# رصيد — نماذج التصميم (Mockups)

افتح `index.html` في المتصفح (أو `npx http-server rased-mockups`). المعرض يعرض كل شاشة في ثلاثة إطارات أجهزة متجاورة (جوال 390، لوحي 834/1194، حاسوب 1440) تحمّل الصفحة نفسها، مع تبديل الوضع والصلاحية واتجاه اللوحي.

| المسار | المحتوى |
|---|---|
| `index.html` | المعرض |
| `logo/palettes.html` + `logo/svg/` | 8 لوحات ألوان للشعار + 24 ملف SVG |
| `direction-1/` … `direction-7/` | 5 شاشات لكل اتجاه + `style.css` و`app.js` |
| `screenshots/` | 210 لقطة للاتجاهات + لقطتا الشعار |
| `DESIGN-PLAN.md` | الخطة والمراجعة قبل البناء |
| `CHECK-REPORT.md` | نتيجة الفحص الإلزامي (280/280) |
| `shared/` | رمز الريال الرسمي (SVG)، `core.js` للوضع والصلاحية |
| `tools/` | `check.js` (الفحص) و`shoot.js` (اللقطات) |
