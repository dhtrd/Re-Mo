# 09 — الضوابط المحاسبية

**الحالة:** DESIGN_DRAFT. اختبارات مرجعية **لا تعتمد على نظام محاسبي فعلي** ولا على أرقام حقيقية. النظام المحاسبي المستهدف UNKNOWN (ADR-005/008). لا تعدّل البيانات لإجبارها على التوازن، وتُعرض الفروقات ولا تُصحَّح بصمت.

## 2. حالات اختبار مرجعية (بيانات اصطناعية)
كل مجموعة بيانات تحمل وسم `SYNTHETIC` واضحًا.

| Test | السيناريو | المتوقع |
|---|---|---|
| ACC-001 | ميزان مراجعة متوازن اصطناعي | يُقبل، ولا فروقات |
| ACC-002 | ميزان غير متوازن بفرق معروف | يُعرض الفرق كما هو، ويُصعَّد، ولا يعدَّل |
| ACC-003 | قيد مسودة بمدين ≠ دائن | يُرفض قبل العرض |
| ACC-004 | قيد في فترة مقفلة | يُرفض مع سبب |
| ACC-005 | إرسال نفس المصدر مرتين | مسودة واحدة (منع تكرار) |
| ACC-006 | رصيد مصدر ≠ معالج | الفرق مسجل ومفسر |
| ACC-007 | تقريب عملات متعددة اصطناعية | نتائج مطابقة للقاعدة الموثقة |
| ACC-008 | محاولة ترحيل من وكيل المالية | تُرفض لعدم وجود الأداة |
| ACC-009 | موافقة منتهية قبل الترحيل | تُرفض |
| ACC-010 | قيد بلا مستند مصدر | يرفض في التحقق |
