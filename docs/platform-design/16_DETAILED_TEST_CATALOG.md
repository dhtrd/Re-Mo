# 16 — كتالوج الاختبارات المفصّل

**الحالة:** DESIGN_DRAFT. **لا اختبار نُفذ ولا يوجد نظام لتشغيله.** يوسّع `10` ويستعمل بادئاته. بيانات الاختبار كلها **اصطناعية** وموسومة `SYNTHETIC`: شركتان `CO-A` و`CO-B`، فرعان `BR-A1` و`BR-A2` تحت `CO-A`، ومستخدمون وهميون (`u-viewer`, `u-preparer`, `u-approver`, `u-auditor`, `u-admin`).
**ما يتوقف على قرارات مفتوحة** مكتوب في عمود «اعتماد على»، ولا تُنفذ الاختبارات قبل حسمه.

**القالب:** ID · الهدف · شرط سابق · البيانات · الخطوات · المتوقع · معيار النجاح/الفشل · الدليل · يغطي · اعتماد على.
