# 15 — استمارة المالك (الأسئلة المانعة لـG1)

**الحالة:** DESIGN_DRAFT · **الغرض:** جمع المعلومات التي تحجب القرارات المفتوحة. كل إجابة تُسجَّل كـUSER-APPROVED بعد تعبئتها.
**طريقة التعبئة:** اكتب الإجابة أسفل كل سؤال، أو «لا أعرف» أو «أحتاج دراسة». لا تكتب أسرارًا أو كلمات مرور أو مفاتيح أو بيانات شخصية. أسماء الأنظمة تكفي.
**أثر الإجابة:** بعد التعبئة تُحدَّث `02` و`04`، وتُزال وسوم BLOCKED المقابلة.
