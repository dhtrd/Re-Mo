# 18 — ملخصات القرار للقرارات المانعة

**الحالة:** DESIGN_DRAFT. **اختارها Claude** (D-010) لأنها لا تتطلب معلومة ناقصة. كل «توصية» PROPOSED وليست قرارًا. لا أسماء مزودين: لم يُتحقق من توفر خدمات أو مناطق أي مزود.
**كيف تستعملها:** اقرأ ملخص كل قرار، ثم أجب أسئلته في `15`. الخانة «إن لم تعرف» تعطيك مسارًا آمنًا مؤقتًا لا يغلق الباب.

---

## ADR-002 — هيكل الشركات والفروع والمستأجرين (يحجب: `04`)

**السؤال الجوهري:** إذا أخطأ برنامج مرة واحدة، هل يرى مستخدم شركة A بيانات شركة B؟ والخيارات تتفاوت في «كم يكلف منع ذلك».

| الخيار | العزل | التشغيل والتكلفة | يناسب إذا |
|---|---|---|---|
| أ. قاعدة مشتركة + معرّف شركة مفروض في طبقة البيانات | منطقي. قوته تعتمد على صحة التطبيق | الأبسط والأرخص | الشركات تابعة لمؤسسة واحدة وتتشارك الإدارة |
| ب. schema منفصل لكل شركة | أقوى | تعقيد ترحيل وصيانة متوسط | عزل تعاقدي أو رقابي متوسط |
| ج. قاعدة منفصلة لكل شركة | الأقوى | الأعلى تكلفة وتشغيلًا | شركات ذات كيانات قانونية وملاك مختلفين، أو اشتراط عزل صريح |

**ما تحتاج أن تعرفه لتحسم:** عدد الشركات (Q4) · هل لها كيانات قانونية وملاك مختلفون (Q4) · هل تتشارك المستخدمين (Q5) · هل يوجد اشتراط عزل في عقد أو نظام (Q5).
**إن لم تعرف:** نخطط على (أ) مع تصميم يسمح بالانتقال إلى (ب) أو (ج) لاحقًا (المعرّف في كل جدول والنطاق من الجلسة). **تكلفة هذا الخيار:** الانتقال لاحقًا ممكن لكنه عمل. **خطر:** إن تبيّن أن العزل مفروض تعاقديًا فستُعاد أجزاء من `04`.

## ADR-003 — السحابة والمنطقة وموقع البيانات (يحجب: `12` والتكلفة والاستعادة)

**السؤال الجوهري:** أين يجوز أن تُخزَّن البيانات وتُعالج (ومنها ما يُرسل إلى مزود النموذج)؟

**معايير المفاضلة (لا أسماء):**
1. إقامة البيانات: داخل المملكة فقط، أم يجوز خارجها لفئات معينة؟
2. توفر خدمات الهوية والتخزين والمراقبة في المنطقة المطلوبة.
3. موقع معالجة النماذج (قد يختلف عن موقع التخزين، وهو بند منفصل في ADR-004).
4. التكلفة والالتزامات التعاقدية.
5. قدرة الفريق وخبرته (UNKNOWN: لا فريق محدد).
6. اشتراطات الجهات المنظِّمة المنطبقة (Q3).

**ما تحتاج أن تعرفه:** Q1 · Q2 · Q3 · Q16.
**إن لم تعرف:** **لا نثبّت مزودًا.** نبقى بتصميم محايد (كما في `03` و`12`) ونطلب مراجعة امتثال قبل G1 (E1-05). هذا القرار الوحيد الذي لا أنصح بتخمينه: قراره الخاطئ مكلف ويصعب عكسه.

## ADR-005 — المصادر الرسمية للبيانات (يحجب: كل الوكلاء)

**السؤال الجوهري:** من «مصدر الحقيقة» لكل نوع بيانات؟ الوكيل لا يعمل إلا على مصدر مسمّى.

| الإدارة | ما أحتاجه منك |
|---|---|
| المالية | اسم النظام المحاسبي، وهل يصدّر ميزان المراجعة |
| المشتريات/المخزون | النظام، وهل أوامر الشراء والاستلام والفواتير في نظام واحد |
| الموارد البشرية | النظام، ومن يملك الاطلاع |
| المبيعات/التشغيل | النظام أو الملفات الدورية |
| المخاطر/المراجعة | هل توجد سجلات رقمية أم ملفات |

**إن لم تعرف:** في G3 نستعمل بيانات اصطناعية أو ملفات تعتمدها أنت، ويُكتب المصدر الرسمي لاحقًا. لا وكيل يُفعَّل على بيانات حقيقية قبل تسمية المصدر.

## ADR-007 — الأدوار والصلاحيات والموافقات (يحجب: `06`)

**السؤال الجوهري:** من يملك حق قول «نعم» على ماذا، وإلى أي مبلغ؟ **لن أخترع أرقامًا.**

**ما أحتاجه:** (Q8) قائمة المناصب · (Q9) سياسة التفويض الحالية · (Q10) حدود الاعتماد · (Q11) ما يُعد «جوهريًا» فيبطل الموافقة.
**طريقة سهلة للإجابة:** املأ هذا الجدول ولو بنصف الخانات:

| نوع المعاملة | من ينشئ | من يعتمد | حد المبلغ (أو «لا أعرف») | من يعتمد فوق الحد |
|---|---|---|---|---|
| قيد محاسبي | | | | |
| طلب شراء | | | | |
| تغيير بيانات مورد | | | | |
| تقرير للنشر | | | | |

**إن لم تعرف:** القاعدة المؤقتة المقترحة: **كل ما له أثر خارجي يتطلب اعتماد شخصين مستقلين** حتى تحدد الحدود، وهذا أشد من اللازم وتخفّفه أنت لاحقًا. الأفضل أن يكون الخطأ في جهة التشدد.

## ADR-008 — الأنظمة الخارجية والتكاملات (يحجب: بوابة الأدوات)

**السؤال الجوهري:** كيف نصل لبيانات كل نظام: API، تصدير ملفات، أم لا شيء؟

| طريقة الوصول | المخاطر | ملاحظة |
|---|---|---|
| API للقراءة | مفاتيح/صلاحيات تُدار في خزنة | الأفضل للاستمرارية |
| تصدير ملفات دورية | تأخر البيانات، وتحقق من سلامة الملف | مناسب لـG3 |
| API للكتابة | أثر خارجي مباشر | **لا قبل G4 وتصريح مستقل** |

**إن لم تعرف:** نبدأ بتصدير الملفات وقراءة فقط. لا موصل كتابة يُصمَّم تفصيليًا قبل معرفة النظام.

## جدول ملخص

| القرار | ما يكفي لأحسمه معك | الخيار الافتراضي إن لم تعرف | ثمن الافتراضي |
|---|---|---|---|
| ADR-002 | Q4, Q5 | (أ) قابل للترقية | قد يُعاد جزء من `04` |
| ADR-003 | Q1–Q3, Q16 + مراجعة امتثال | **لا افتراضي** | يؤخر G1 |
| ADR-005 | Q6 | بيانات اصطناعية في G3 | لا وكلاء على بيانات حقيقية |
| ADR-007 | Q8–Q11 | اعتماد شخصين لكل أثر خارجي | بطء مؤقت |
| ADR-008 | Q7 | تصدير ملفات + قراءة فقط | بيانات أقل حداثة |

## افتراضات في هذا الملف
- افترضت أن الخيار (أ) أرخص وأبسط، وهذا حكم عام ولم أقِسه على تقنية بعينها.
- «تكلفة» و«تعقيد» نوعيان فقط، بلا أرقام.
- لم أتحقق من أي متطلب نظامي سعودي. الإقامة والإشعار ونقل البيانات نقاط لمراجعة مختص.
